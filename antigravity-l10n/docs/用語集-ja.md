# 用語集（日本語）

辞書（`locales/ja/`）の訳語をそろえるための一覧です。製品名・モデル名・プロトコル名は英語のまま（Antigravity、Gemini、Claude、MCP、Git、GitHub、Chrome など）。

## 表記ルール

- 説明文・メッセージは「です・ます」調。ボタン・メニュー・見出しは体言止め（「保存」「名前を変更」）。
- 日本語と英数字の間には半角スペースを入れる：`Google アカウント`、`3 件`。
- カタカナ語が続くときは、Google の製品表記に合わせて単語の間に半角スペースを入れる：`ターミナル コマンド`、`リモート コントロール`。一語として定着しているものはつなげる：`サイドバー`、`アドレスバー`。
- 句読点は「、」「。」、括弧は全角（）、コロンは全角「：」。
- 長音は付ける：`サーバー`、`フォルダー`、`ユーザー`（ただし `ブラウザ`、`フィルタ` は慣用に合わせて付けない）。
- 読み込み中などの状態表示は `読み込み中…`、省略記号は `…`。
- 件数は「件」：`3 件のコメント`、`エージェント 3 件が実行中`。
- ファイル名・コマンド・パス・キー名・コードは原文のまま：`/browser`、`task.md`、`Ctrl+Enter`。
- 名前を引用するときは「」：`「{0}」を削除`。
