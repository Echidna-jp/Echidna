# 术语表

翻译词典时统一使用下面的译法。产品名、模型名、协议名保留英文（Antigravity、Gemini、Claude、MCP、Git、GitHub、Chrome 等）。

## 写法约定

- 人称用「你」，能省略就省略。
- 中文与英文、数字之间留一个半角空格：`使用 Google 账号继续`、`3 个文件`。
- 句子用全角标点（，。：？！）；按钮、菜单项、标题末尾不加句号。
- 加载、进行中状态用「正在…」，省略号统一用 `…`：`Loading...` → `正在加载…`。
- 键名、命令、路径、文件名、代码保留原样：`/browser`、`task.md`、`Ctrl+Enter`。
- 带变量的句子写成 patterns（`{0}`、`{1}` 占位），译文可以调换占位符顺序。
